# CanteenConnect 🍽️

CanteenConnect is an Android application designed to make canteen-related services easier to access through a simple, user-friendly interface.

## ✨ Features

- User login and authentication interface
- Forest-green and white user interface
- Dedicated app screens built with Jetpack Compose
- Custom CanteenConnect branding and logo

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **IDE:** Android Studio
- **Platform:** Android

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and finish downloading dependencies.
4. Select an Android emulator or connect an Android device.
5. Click **Run ▶** to launch the app.
