# CanteenConnect

CanteenConnect is a Flutter/Dart starter app with a forest-green and white interface.

## Features in this starter
- Login screen with basic form validation (demo only; no real authentication backend)
- Home dashboard
- Sample canteen list
- Interactive in-memory shopping list
- Profile placeholder and sign-out
- Optional custom logo in `assets/images/`

## Requirements
- Flutter SDK
- Android Studio (with Flutter and Dart plugins)
- An Android emulator or device

## Run locally
```bash
flutter pub get
flutter run
```

## Project status
This is a starter recreation. Replace sample canteen data and demo login with your actual app services before production use.
